# InteresMe Client

Frontend application for the InteresMe platform.

InteresMe is a social discovery platform focused on meaningful connections through interests, goals, projects, and lifestyle.

---

## Tech Stack

- Angular
- TypeScript
- Tailwind CSS
- Docker
- Nginx

---

## Development

Run locally:

```bash
ng serve

Development URL:

http://localhost:4200
Docker

Build image:

docker build -t interesme-client .

Run container:

docker run -p 5050:80 interesme-client

Production URL:

http://localhost:5050
