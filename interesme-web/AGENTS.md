# InteresMe Frontend

## Project

InteresMe is a platform around:

- Interests
- Initiatives
- Communities
- User Journeys

People connect through activity.

Not through appearance.

Do not turn InteresMe into:

- Tinder
- LinkedIn
- Instagram
- TikTok

## Core Principles

- Initiatives are primary.
- Profiles are secondary.
- Interests are a structured map.
- History is a user journey.
- Follow means following activity, not appearance.

## Stack

- Angular 20
- Standalone Components
- Signals
- SCSS

## Development Rules

Before implementing:

1. Inspect existing routes.
2. Inspect existing components.
3. Inspect existing services.
4. Reuse existing patterns.
5. Extend before creating.

## Angular Rules

Prefer:

- Standalone Components
- Signals
- Computed Signals
- Typed models

Avoid:

- unnecessary RxJS complexity
- duplicated state
- duplicated services
- giant components

## API Consumption

Frontend should not compensate for missing backend architecture.

If a page requires many requests:

Propose a backend aggregate endpoint.

Good:

GET /profile-view

Bad:

GET profile
GET interests
GET history
GET followers
GET initiatives

## UI Philosophy

Every screen should help users:

- discover initiatives
- discover interests
- discover people
- build communities
- follow journeys

Do not add features simply because other social networks have them.

## Design

InteresMe style:

- warm light theme
- near-black dark theme
- teal/mint accents
- orange brand accent
- rounded cards
- student-first aesthetic

## Avoid

Avoid:

- infinite feeds
- engagement farming
- vanity metrics
- popularity-first design
- TikTok layouts
- Instagram layouts
- LinkedIn layouts
- Tinder layouts

Unless explicitly requested.

## Profile Rules

Profile should feel like:

- a character page
- a journey page
- an activity summary

Not:

- a CV
- a dating profile

## Interests Rules

Interests should feel like:

- exploration map
- structured catalog

Not:

- feed
- endless scrolling

## History Rules

History should feel like:

- timeline
- progression
- GitHub activity

Not:

- feed
- social content stream
